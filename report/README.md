# Report — build instructions

LaTeX source for the project report. Output: `main.pdf` (13 pages).

## Structure
- `main.tex` — preamble, title, abstract, TOC, includes chapters, bibliography
- `references.bib` — all cited works
- `chapters/01..05.tex` — Introduction → Architecture → Data & Methodology → Results → Discussion & Conclusion
- `figures/` — result charts (generated by `backend/experiments/plot_results.py`)

## Compiling

### Option A — Overleaf (easiest)
Upload the whole `report/` folder, set the compiler to **pdfLaTeX**, compile. Overleaf's TeX Live includes the Vietnamese `T5` font encoding (`vntex`) used here.

### Option B — Local pdfLaTeX
Requires TeX Live with: `texlive-latex-extra`, `texlive-fonts-recommended`,
`texlive-lang-other` (T5/Vietnamese), `lmodern`, `latexmk`.
```bash
cd report
latexmk -pdf main.tex
```

## Notes
- Vietnamese is handled via `\usepackage[utf8]{inputenc}` + `\usepackage[T5]{fontenc}` + `lmodern`. The text is written in literal UTF-8 — **do not** use `[T1]` as the default encoding or Vietnamese glyphs (ế, ư, đ, …) will fail to typeset.
- All result numbers/figures come from the 80-question evaluation; regenerate figures with `python experiments/plot_results.py` (and the inline `retrieval_gains.png` / `qe_compare.png` scripts) if the CSVs change.
